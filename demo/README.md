# Bright2Nuc inference demo

`bright2nuc_fold0_test.npy` contains 64 brightfield per-nucleus crops used to demonstrate inference with the released M3 deep ensemble.

The array has shape `(64, 16, 64, 64)` and dtype `uint8`.

## Source dataset

- Dataset: Bright2Nuc
- DOI: https://doi.org/10.5281/zenodo.7014598
- License: Creative Commons Attribution 4.0 International (CC BY 4.0)
- Original repository: https://github.com/marrlab/Bright2Nuc

This file is provided as a small reproducible inference example. The complete Bright2Nuc dataset is not redistributed by this repository.
